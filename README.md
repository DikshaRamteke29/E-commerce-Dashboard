# E-commerce-Dashboard
1 Project Title

E-Commerce Sales Dashboard using Power BI

2 Project Overview

The E-Commerce Sales Dashboard is a business intelligence and data visualization project developed using Power BI. This dashboard provides a complete analysis of e-commerce sales and profit performance across different product categories, cities, quarters, and years.

The project transforms raw business data into interactive visual insights that help understand sales growth, profit distribution, top-performing locations, and category-wise business performance. The dashboard enables businesses to make better strategic decisions using data-driven insights.

This dashboard is designed with a professional dark-themed UI and interactive visuals for better user experience and easy business analysis.

3 Tech Stack Used

Technology	Purpose

Power BI	Dashboard development and visualization

Power Query	Data cleaning and transformation

DAX (Data Analysis Expressions)	Calculated measures and KPIs

Excel / CSV Dataset	Data source

Data Modeling	Data relationships and organization

4 Data Source

The dataset used in this project was taken from Kaggle and contains historical e-commerce sales records including sales, profit, product categories, customer locations, and order details.

The dataset was cleaned and transformed using Power Query before creating interactive visualizations in Power BI.

5 Dashboard Features & Visualizations
1️ Total Profit by Category

A bar chart visualizes profit generated by different product categories.

Example:

Copiers generated the highest profit
Binders and Accessories also performed strong

2 City-wise Profit Analysis

A horizontal bar chart displays profit contributions from different cities.

Example:

Los Angeles generated the highest profit
Seattle and San Francisco are also top-performing cities

3️ Yearly Sales & Profit Trends

A combination chart compares yearly sales and profit performance.

Example:

Sales and profit increased significantly in 2014
Business growth improved year by year

4️ Quarterly Sales Distribution

A pie chart shows sales contribution by quarter.

Example:

Quarter 4 contributed the highest sales share

5️ Quarterly Profit Distribution

Another pie chart represents profit distribution across quarters.

Example:

Quarter 4 generated maximum profits

6️ Interactive Filters & Slicers

The dashboard includes filters for:

State Selection
Date Range Selection

Example:

Selecting “California” updates all charts dynamically for California data only.

7️ Dynamic Dashboard Interaction

All visuals are interconnected.

Example:

Clicking on a category updates related sales and profit charts automatically.

6 Business Problem

E-commerce companies generate large amounts of sales and transaction data daily. Analyzing this data manually is time-consuming and inefficient.

Businesses often face challenges such as:

Identifying profitable products

Understanding regional performance

Tracking sales growth

Improving profit margins

Detecting seasonal trends

This dashboard solves these problems by converting raw data into meaningful visual insights, helping businesses make smarter and faster decisions.
